# 🧰 Technologies Recipes

## 📖 Overview
This section collects recipes about specific technologies rather than architectural patterns. Each one explains the main concepts of a tool, so the pattern recipes that use it are easier to follow.

The goal is to give a short, ordered learning path for each technology, where every concept has its own page, an example, and a diagram.

Understanding a technology's building blocks makes it easier to choose it, configure it, and compare it with alternatives.

Start with the technology you use, read its pages in order, and then follow the links to the related pattern recipes.
